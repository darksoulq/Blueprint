Glyphs

Glyphs allow players to type placeholders (like :smile:) in chat (optional), which are replaced by custom images.

File Structure

Glyphs require a YAML configuration and a .png texture file.

Configuration: plugins/Blueprint/content/<namespace>/data/glyphs/<group>.yml Texture: plugins/Blueprint/content/<namespace>/assets/textures/<texture_name>.png

YAML Configuration

glyphs: smile: type: "bitmap" file: "smile_icon" height: 9 ascent: 8 allow_in_chat: true chat_use_permission: "blueprint.glyph.smile" show_in_dictionary: true

Configuration Fields

Field

Type

Description

type

String

Font provider type. Defaults to bitmap.

file

String

PNG file name in the assets folder (excluding the .png extension).

height

Integer

Rendering height of the glyph.

ascent

Integer

Vertical shift of the glyph relative to the text baseline.

allow_in_chat

Boolean

Allows players to type this glyph's ID to render it in chat.

chat_use_permission

String

Permission required to use this glyph. Leave blank for no permission requirement.

show_in_dictionary

Boolean

Includes this glyph in the /bp dictionary book.
