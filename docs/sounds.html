Sounds

Register custom audio files as playable sound events in-game.

File Structure

Place the YAML configuration in data, and the raw .ogg files in assets.

Configuration: plugins/Blueprint/content/<namespace>/data/sounds/<file>.yml Audio: plugins/Blueprint/content/<namespace>/assets/sounds/<sound_name>.ogg

YAML Configuration

Keys in the YAML represent the Sound Event ID (e.g., /playsound <namespace>:<event_key>).

custom.sword.swing: category: "player" subtitle: "Sword swings" replace: false sounds: - name: "sword_swing_1" volume: 1.0 pitch: 1.0 weight: 1 - name: "sword_swing_2" volume: 1.0 pitch: 0.8

Configuration Fields

Field

Type

Description

category

String

The mixer category (e.g., master, player, hostile). Defaults to master.

subtitle

String

The translation key shown in subtitles when this sound plays.

replace

Boolean

If true, replaces existing sounds registered under this event ID instead of appending to them.

sounds

List

List of sound variants. The name field must match an .ogg file in your assets folder without the extension.
